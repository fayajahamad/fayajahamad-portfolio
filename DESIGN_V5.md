# V5 — Heritage Gold portfolio

This version implements the owner-supplied palette:

| Name | Hex | Usage |
| --- | --- | --- |
| Antique gold | `#D9B061` | Primary actions, visual highlights, portrait border |
| Champagne | `#D9C4A9` | Supporting text and subtle highlights |
| Stone | `#D8D0C5` | Soft neutrals |
| Walnut | `#8D6F57` | Borders and quiet labels |
| Wine | `#3F0D0C` | Heritage dark branding and navigation |

The source portrait was supplied by the site owner and embedded as an optimized WebP without changing facial features or composition. It is rendered on Home and About using Next.js Image.

The original V4 code remains the foundation. Featured lab diagrams and the interactive allow/deny access example remain in the website. The main page now prioritizes the person and technical projects instead of a large dashboard panel.

> **Verification:** Before publishing, run `npm.cmd install`, `npm.cmd run check`, and `npm.cmd run build` on Windows. Check responsive layout and portrait crop in Chrome. No fake claims or stats were introduced.

The name stays `fayajahamad-portfolio`. No changes to GitHub or Vercel are made by this ZIP.
